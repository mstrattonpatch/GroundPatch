QGIS styling script

Your shapefiles are downloading. Load them into QGIS, then follow the steps below to style everything automatically.

How to run it

1In QGIS, go to Plugins → Python Console (or Ctrl+Alt+P).
2Click Show Editor (top-left icon), paste the script below into it, then click the green Run arrow.
